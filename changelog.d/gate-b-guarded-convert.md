### Added

- `taosmd migrate --convert-vectors` converts a vector store's dense embeddings from JSON text to base64 float32 under guard. It takes an exclusive lock, checks free space, writes a verified backup with the sqlite backup API to `backups/vector-memory.<UTC time>.pre-f32.db`, converts in one transaction in bounded batches, and before committing re-reads every row from the backup (new float32 values equal the cast of the original, all other columns unchanged, identical top-10 results for 20 stored vectors used as queries). Any failure rolls back and leaves the store byte-identical. Unreadable rows are left as they are and listed; more than 1% unreadable refuses the run. Exit codes: 0 converted or already current, 2 refused with nothing touched, 3 unknown or newer format, 4 failed and restored, 1 unexpected. The backup is always kept. Plain `taosmd migrate` is unchanged.
