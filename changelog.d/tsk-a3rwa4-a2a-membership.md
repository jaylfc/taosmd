### Added
- A2A thread membership management via a new `MembershipStore` (in `taosmd/a2a_membership.py`) backed by a dedicated `a2a-membership.db` SQLite database with a schema migration. The `service` layer exposes `a2a_create_thread`, `a2a_list_members`, `a2a_add_member`, and `a2a_remove_member` -- callers become thread owners, participants are members, and removal is zero-loss (rows are marked inactive, not deleted). Threads with no membership rows remain open to all for backward compatibility. The `RemoteClient` and HTTP server forward the same four operations for remote use.
