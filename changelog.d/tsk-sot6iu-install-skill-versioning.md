### Fixed
- `taosmd install-skill` now compares the packaged skill `version` (from the SKILL.md frontmatter) against the installed copy and records a content hash in a `.taosmd-skill-manifest.json` at install time. A stale install with a newer package upgrades in place by default (no longer silently exits 0 with "already installed"); a copy carrying local edits is refused without `--force` so user edits are never silently clobbered.
- Versions are ordered as tuples of dotted integers rather than compared for equality, so an older packaged skill no longer replaces a newer installed one while reporting an "upgrade". A downgrade is refused unless `--force` is passed, and a move the tool cannot order (either side is not a plain numeric version, as on every pre-versioning install) is reported as "replaced" instead of "upgraded".
- A truncated or otherwise unreadable `.taosmd-skill-manifest.json` no longer raises out of `install-skill`. It is treated as unknown provenance and falls back to the content comparison, on the default path and the `--force` path alike, so the escape hatch the error message advertises stays reachable.
