# Hand-off: exec PR body generator misstates its own diff

## Finding

The `Files:` block and acceptance narrative in exec PR bodies are generated by
`/home/jay/.taos-team/executor.sh` (lines 1162-1172), which is **outside this
repository**.

## Bug 1: `Files:` block uses an empty merge base

```bash
# executor.sh lines 1162-1172
PR_URL="$(gh pr create ... \
  --body "... \
$(git -C "$WT" log -1 --format='%b')

_MERGE_BASE="$(git -C "$WT" merge-base HEAD "origin/$PR_BASE" 2>/dev/null)" || _MERGE_BASE="$BASE_SHA"
Files:
$(git -C "$WT" diff --stat "$_MERGE_BASE"..HEAD | tail -8)" 2>"$_PR_ERR")"
```

The `_MERGE_BASE="..."` assignment is **inside the double-quoted `--body` string**.
Shell variable assignments inside a quoted string are literal text; they do not
create a shell variable. The subsequent `$(git -C "$WT" diff --stat "$_MERGE_BASE"..HEAD)`
expands `$_MERGE_BASE` from the **parent shell**, where it is unset, so the
command becomes:

```
git -C "$WT" diff --stat "..HEAD" | tail -8
```

`..HEAD` (empty left side) does not refer to the merge base. The result is a
`Files:` block that does not match the actual diff. In the worst case observed
(PR #357), the block listed 24 files and 1863 insertions belonging to a
different PR's branch (#349), because the diff was computed against the wrong
ref.

## Bug 2: Acceptance narrative omits demanded proofs

The PR body includes only the head commit message (`git log -1 --format='%b'`).
The executor runs pytest, vitest, and typecheck gates before opening the PR,
but their results are never written into the body. A card demanding a suite
count or byte measurement therefore sees silence in the PR description, which
reads as "done" when it is not.

## Fix (for executor.sh maintainer)

1. Compute `_MERGE_BASE` **before** the `--body` string as a real shell
   variable:

   ```bash
   _MERGE_BASE="$(git -C "$WT" merge-base HEAD "origin/$PR_BASE" 2>/dev/null)" || _MERGE_BASE="$BASE_SHA"
   ```

2. Reference the variable inside the body:

   ```bash
   --body "... \
   $(git -C "$WT" log -1 --format='%b')

   Files:
   $(git -C "$WT" diff --stat "$_MERGE_BASE"..HEAD | tail -8)"
   ```

3. Append proof blocks for gates that ran:

   ```bash
   _proof=""
   if [ -f "/tmp/verify-$TASK.log" ]; then
     _proof="$_proof

> **Python tests:** $(tail -3 /tmp/verify-$TASK.log | tr '\n' ' ')"
   fi
   if [ -f "/tmp/verify-vitest-$TASK.log" ]; then
     _proof="$_proof

> **Vitest:** $(tail -3 /tmp/verify-vitest-$TASK.log | tr '\n' ' ')"
   fi
   # ... similarly for typecheck, taosctl gate, etc.
   ```

   If a gate was skipped (e.g. no node_modules), the body should say so
   explicitly rather than omit it.

## Why this is a hand-off, not a build

The generator is a shell script in `~/.taos-team/`, not a module inside this
repository. Fixing it requires editing that script, which is owned by the
executor maintainer. This repo contains only the code that the executor builds
and the gates that verify it.
