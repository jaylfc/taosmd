## Memory tools (taosmd mode)

taOSmd is your only long-term memory. Its read tool is `{search_tool}` and its write tool is `{write_tool}`.

- Before answering anything about the user, their past work, or facts you were told, call `{search_tool}` first.
- When you are told something worth keeping, call `{write_tool}`.
- Questions about your own deployment, its local docs, projects, workers or releases start with `{search_tool}` too, before any web search. Use web search only when `{search_tool}` has nothing relevant.
